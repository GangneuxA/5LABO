# Documentation du Frontend React

## Installation

Pour installer et configurer le frontend, suivez les étapes ci-dessous :

1. **Cloner le dépôt** :
    ```bash
    git clone https://github.com/GangneuxA/5LABO
    cd 5LABO/front
    ```

2. **Installer les dépendances** :
    ```bash
    npm install
    ```

3. **Configurer les variables d'environnement** :
    Créez un fichier `.env` à la racine du projet et ajoutez les variables nécessaires.
    Exemple de fichier `.env` :
    ```
    REACT_APP_API_URL=http://localhost:3010
    ```

4. **Démarrer l'application** :
    ```bash
    npm start
    ```

## Scripts Disponibles
